Free to try. Runs on your own machine.

Windows

The packaged build

Get it

Download from GitHub Releases

Grab the SoloTone-v…-windows.zip from the newest release, unzip it anywhere, and run the .exe — no Python, nothing to install. The user guide is in the zip.

Heads up

The build isn't code-signed yet, so Windows SmartScreen may warn on first run. Click More info, then Run anyway. A signed build and a one-click installer are planned.

macOS & Linux

From source — four steps, once

Install Python

Version 3.10 or later, from python.org if you don't already have it.

Get the source

Clone the repository or download it as a zip.

Install the dependencies

pip install -r requirements.txt — on Linux, first sudo apt install libportaudio2 portaudio19-dev python3-tk.

Launch it

python solotone.py — that's the whole rig, open and ready.

Recording

Getting SoloTone into a DAW

SoloTone doesn't have a plugin (VST/AU) version — it's a standalone app with its own audio stream — but its output can still be routed into a DAW for recording, using a free virtual audio mixer: VoiceMeeter.

Install VoiceMeeter

Free, from VB-Audio. It creates virtual audio devices your DAW and SoloTone can both see.

Set SoloTone's output

On the I/O & Levels tab, set Output to the VoiceMeeter virtual input instead of your speakers/interface.

Fan it out to both places

VoiceMeeter can send that same signal to your real speakers/headphones and the virtual cable at once — so you keep low-latency monitoring while the DAW records in parallel.

Record in your DAW

Point your DAW's input at the matching VoiceMeeter virtual output and hit record.

A simpler single-purpose loopback like VB-CABLE also works, but it won't give you real-time monitoring the way VoiceMeeter's fan-out does — you'd only hear what the DAW plays back, with its own added latency on top of SoloTone's.

You'll need

A microphone or audio interface for the tuner and looper to hear you — your laptop's built-in mic works to get started.

You won't need

An account, a subscription, or an internet connection once it's installed. SoloTone never phones home.

Free to use

SoloTone costs nothing and never will for the basics. If it's useful to you, a tip on Ko-fi helps cover the time spent building it.
